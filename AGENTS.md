# Repository Rules

## Documentation Language

- All documentation added to or modified in this repository must be written in English.
- This rule applies to Markdown files, documentation-site content, architecture and design documents, specifications, changelogs, release notes, examples whose primary purpose is documentation, and user-facing explanatory text committed to the repository.
- Keep code identifiers, commands, paths, protocol fields, and quoted external text in their required original form.
- Existing non-English documents do not need to be translated unless they are being substantively updated. Any new or rewritten sections in those documents must be in English.
- Before completing a documentation change, review the changed documentation for non-English prose and translate it to English.
